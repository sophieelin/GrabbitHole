## Solution Sketch: Grabbithole

Grabbithole will act as a tool for visualizing and saving research paths.

Each research project has its own research space on Grabbithole, which can be used individually or shared among multiple researchers. While researching, users can turn on Grabbithole's browser extension to record the websites they visit, with option to add explanatory notes specific to each website. After each session, a preliminary graph is saved, with each link represented as a node and the lines between nodes representing how the user moved from one link to another. Backtracking allows one node to connect to multiple others. Users can then review their graph, remove irrelevant links, manually edit connections, and add/edit notes explaining the importance or relevance of each source and connection.

Once a research session is added to a project, Grabbithole combines its sources and connections with the existing graph, representing links with matching URLs as the same node while preserving their original connections. An LLM then automatically assigns new sources to existing topic groups or creates new groups when necessary, without reorganizing previously added sources. Users can manually adjust these groupings if needed.

For collaborative projects, multiple researchers work within the same shared research space. Each researcher records their browsing sessions independently and can propose adding their preliminary graph to the shared project graph. The project owner/authorized collaborators can review and approve these contributions before they are incorporated.

While contributing allows researchers to add their findings to an existing shared project, forking allows them to explore different directions independently. A researcher can fork an existing graph at a particular node, creating a separate project space without modifying the original. Grabbithole records which graph the fork originated from and where the researcher branched off. Researchers can continue developing their fork independently and may later propose contributing their findings back to the original project. If their contribution is rejected, their independent graph remains unchanged.

Other users can also search through Grabbithole and treat it as an archive of research paths. If their search matches a node or topic, public research graphs containing relevant sources will be displayed, even if the graphs originally explored different subjects. Users can follow these paths to discover other sources, fork a graph to continue their own research, or propose additions to an existing project if contributions are enabled.
