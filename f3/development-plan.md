# Development Plan

## 1. Timeline

| Date | Stage | Expected Deliverables |
|---|---|---|
| Nov 16–19 | Concept Design | Finalize concepts and synchronizations and set up project structure and database. |
| **Nov 23** | **Alpha** | Create research projects, add and connect sources, and visualize basic graphs. |
| **Nov 30** | **Beta** | Browser extension, AI topic grouping, contributions, and basic forking. |
| Dec 7 | User Testing | Test core workflows, collect feedback, and fix major issues. |
| Dec 9 | Final Demo | Polish UI, resolve bugs, and complete documentation. |

## 2. Team Responsibilities

| Member | Responsibility |
|---|---|
| Person 1 | DiscoveryLinking and browser extension |
| Person 2 | Grouping and Claude integration |
| Person 3 | Contributing, collaboration, and forking |
| Person 4 | Frontend and graph visualization |
| Everyone | Integration, testing, and documentation |

## 3. Key Risks and Fallbacks

| Risk | Mitigation / Fallback |
|---|---|
| Browser extension complexity | Start with basic tracking and fall back to manual link entry. |
| Graph visualization becomes cluttered | Use an existing graph library and simplify to collapsible topic groups if needed. |
| AI grouping is inaccurate | Allow manual corrections and fall back to manual grouping. |
| Collaboration and merging are difficult | Start with adding new sources and connections. Defer complex merging. |
| Limited development time | Prioritize creating, connecting, saving, and viewing research graphs. |
